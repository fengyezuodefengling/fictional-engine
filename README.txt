机械设计题库｜举一反三
====================

这是一个可部署到 GitHub Pages / Netlify / Vercel 的手机网页版本。

部署后：
1. 浏览器打开网址即可刷题，不需要下载 HTML。
2. 手机浏览器可选择“添加到主屏幕”，像 App 一样使用。
3. 题目、错题、收藏、似会非会等记录保存在浏览器 localStorage 中。
4. 后续更新题库时，用新的 index.html 替换旧文件并重新部署即可。

GitHub Pages 最简单方式：
- 新建一个 GitHub 仓库
- 上传本文件夹中的全部文件
- Settings -> Pages -> Deploy from branch -> main / root
- 等待部署完成后，使用 GitHub 给出的网址即可。

注意：不同手机/浏览器的 localStorage 相互独立；清除浏览器站点数据会清掉本机刷题记录。
